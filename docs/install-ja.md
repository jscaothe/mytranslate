# MyTranslate - インストールと使い方

MyTranslate は、Teams や Slack のチャット欄でそのまま日本語とベトナム語を翻訳する Windows アプリです。
ベトナムの開発チームとやり取りする日本人の方向けの説明です（ベトナム語版: [install.md](install.md)）。

## 必要なもの

| 必要なもの | 補足 |
| --- | --- |
| Windows 10 22H2 または Windows 11 | |
| Claude Code（インストールしてログイン済み） | ターミナルで一度 `claude` を実行してログインします |
| ご自身の Claude アカウント（Pro、Max、Team、Enterprise） | 翻訳はご自身のプランの利用枠を使います。ChatGPT や Gemini の APIキーでも使えます |

## インストール

1. https://mytranslate.pages.dev からダウンロードし、`MyTranslate_<バージョン>_x64-setup.exe` を実行します（管理者権限は不要です）。
2. インストールが終わるとアプリが起動し、**タスクトレイ**（画面右下、^ の中の場合あり）に最小化されます。
   バックグラウンドで動作中であることを Windows の通知でお知らせします。
   トレイの MyTranslate アイコンをクリックするか `Ctrl+Alt+M` を押すと、初期設定ガイドが開きます。
   Windows が日本語なら、アプリは日本語で表示されます。
   初期設定ガイドの最初の画面で「Tiếng Việt / 日本語」を切り替えられます。
3. ガイドに沿って Claude Code との接続を確認し、ベトナム語の文を試しに翻訳します。
4. ウィンドウを閉じてもアプリはタスクトレイで動き続け、ショートカットはいつでも使えます。

「WindowsによってPCが保護されました」と表示されたら、「詳細情報」から「実行」を選んでください（試用版はまだデジタル署名されていません）。

## 毎日の使い方

| 操作 | 内容 |
| --- | --- |
| メッセージを選択して「日本語に翻訳」をクリック | ベトナム語のメッセージを日本語で読みます。選択して `Ctrl+Alt+T` を押しても同じです |
| 入力欄に日本語を書いて `Ctrl+Alt+T` | ベトナム語に翻訳し、日本語に読み返した意味も表示します。`Enter` で入力欄の文がベトナム語に置き換わります |
| ポップアップで `Tab` | ベトナム語の丁寧さ（カジュアル / 丁寧 / とても丁寧）を切り替えます |
| 読むポップアップで `Enter` | 日本語で返信を書くと、ベトナム語に翻訳します |
| 読むポップアップで `G` | AIがベトナム語の返信案を3つ、日本語の意味つきで提案します。クリックでコピーします |
| `Ctrl+Alt+M` | メイン画面を開きます |

アプリが勝手にメッセージを送ることはありません。送信はご自身で行ってください。

### スレッドごとの文脈

アプリは会話とスレッドごとにメッセージを整理し、直前のやり取りも踏まえて翻訳します。
「先ほどの件」「それ」のような表現も、何を指すかが伝わる訳になります。
メイン画面の「スレッド」で、過去のやり取りや AI による日本語の要約を確認できます。

### よりよい翻訳のために

- **連絡先**: 会話ごとに丁寧さと、相手についてのメモ（名前、役割、呼び方。例:「グエンさんは開発リーダーで anh と呼ぶ」）を設定できます。
- **用語集**: 画面名や機能名など、決まった訳語を登録できます。

## 言語の切り替え

設定 > 言語 > 「あなたの言語」で、日本語とベトナム語を切り替えます。
言語を変えると、表示だけでなく「読む」「書く」の翻訳の向きも入れ替わります。

## データとプライバシー

- 翻訳履歴、スレッド、用語集はこのPCの `%LOCALAPPDATA%\com.mytranslate.desktop\history.db` にだけ保存されます。
- 内容は、選択した AI（ご自身の Claude Code、または APIキーを登録した ChatGPT / Gemini）にだけ送信されます。
  アプリ独自のサーバーはありません。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| ショートカットを押しても何も起きない | タスクトレイに MyTranslate のアイコンがあるか確認し、右クリックで「ショートカットを一時停止」がオフか確認します。別のアプリと重なっている場合は 設定 > ショートカット で変更します |
| 「テキストが選択されていません」と表示される | メッセージを選択し直します。入力欄の文を翻訳するときは、文字のある入力欄にカーソルを置いて `Ctrl+Alt+T` を押します |
| 「Claude Code にログインしていません」と表示される | ターミナルで `claude` を実行してログインし、「再試行」を押します |
